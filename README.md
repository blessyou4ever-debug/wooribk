# 우리WON 경조비 매니저 (Android App)

우리WON뱅킹 입출금 알림을 실시간으로 분석하여 **개인에게 이체된 경조비 지출 내역만 자동으로 선별·관리**하는 안드로이드 앱입니다.

## 주요 기능

1. **우리WON뱅킹 출금 알림 자동 분석 및 은행/이름 분리**
   - 패키지명 `com.wooribank.smart.npib`의 입출금 알림 중 `[출금]` 내역만 감지합니다.
   - `신한조창헌`처럼 은행 약칭과 실명이 붙어 있는 타행 이체 내역을 **은행(`신한`)**과 **이름(`조창헌`)**으로 자동 분리합니다.
   - `네이버페이충전`, `K B카드출금`, `NHBC카드대금`, `현대10-063` 등 카드/페이/충전/공과금/영문·숫자 포함 내역은 자동으로 제외합니다.
2. **맞춤형 경조비 금액 단위 필터**
   - 기본 제공 프리셋: **3만 / 5만 / 7만 / 10만 / 15만 / 20만 / 30만 / 50만 / 100만 원**
   - 앱 내 `[백업/설정]` 탭에서 각 금액 단위를 켜고 끌 수 있으며, 원하는 사용자 정의 금액(예: 25만 원, 150만 원)을 직접 추가·삭제할 수 있습니다.
3. **확인 대기 및 경조비 확정·삭제 워크플로우**
   - 알림으로 감지된 내역은 먼저 `[확인 대기]` 탭에 등록됩니다.
   - 사용자가 직접 확인하여 **경조비가 아니면 즉시 삭제**하고, 경조비가 맞으면 **경조 구분(결혼/부고/돌잔치/생신/승진/명절/기타)**, **관계(직장/친구/친척/모임/거래처/기타)**, **메모**를 입력해 장부에 확정할 수 있습니다.
4. **과거 내역 업로드 (2종 양식 모두 지원) 및 기기 백업·복원**
   - **전용 CSV 양식**: 앱에서 `[과거 내역 업로드용 CSV 양식 내려받기]` 버튼으로 샘플 파일을 내려받아 작성 후 업로드할 수 있습니다.
   - **우리은행 거래내역 CSV**: 우리은행에서 내려받은 거래내역 CSV 파일도 그대로 업로드하면 개인 이체 및 경조비 금액 필터를 자동 적용해 가져옵니다.
   - **기기 내 백업/복원**: 전체 데이터와 금액 필터 설정을 JSON 파일로 백업·복원하거나 엑셀 호환 CSV 파일로 내보낼 수 있습니다.

## GitHub Actions 자동 APK 빌드 방법

1. 이 프로젝트 파일들을 본인의 GitHub 저장소(`main` 브랜치)에 업로드(Push)합니다.
2. 저장소 상단의 **Actions** 탭으로 이동하면 `Android APK Build & Release` 워크플로우가 자동으로 실행됩니다.
3. 빌드가 완료되면 워크플로우 실행 결과 하단의 **Artifacts** 섹션에서 **`woori-gyeongjobi-debug-apk`**를 다운로드하여 압축을 풀고 `app-debug.apk`를 안드로이드 휴대폰에 설치합니다.
